State of the evidence

Corrections so far

This list has been wrong in public before and will be again. It said Bitwig's Grid had no MIDI — Note Grid shipped in 4.2, March 2022. It filed LV2 and AUv3 alongside compilers, when they are formats. It lost ten specimens in a rewrite. Each fix is in the git history; the evidence tags exist so the next error is easier to find than the last.

Deliberately not exhaustive

The Eurorack-metaphor family alone could fill this: Voltage Modular, Softube Modular, Multiphonics, Cardinal, miRack, Mela, zMors, Audulus, Caustic, and semi-modular plugins like Unfiltered Audio LION. Several are here as representatives. The test for inclusion is whether a specimen shows something the others don't — otherwise "any synth with a modulation matrix" swallows the cabinet.

Contributing

Data lives in data/systems.json against data/schema.json, with the controlled vocabulary in data/vocabulary.json. The most useful contribution is turning an unv into a chk with a source URL. See CONTRIBUTING.md.
